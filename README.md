# Materio — Privacy Policy / Polityka prywatności / Datenschutzerklärung

Hosting for the public privacy policy of the **Materio** Android app
(`pl.materio.app`).

- Single page, three languages (PL / EN / DE) with a language switcher.
- Deep-linkable: `?lang=pl`, `?lang=en`, `?lang=de`.
- Static HTML, no tracking, no external dependencies.

**Live URL (GitHub Pages):**
`https://3d-polednia.github.io/Materio-polityka-prywatno-ci/`

Use this URL as the *Privacy policy* link in Google Play Console.

Last updated: 16 July 2026.
